# Dependencies

CyberShield Lab Version 1 is frontend-only.

## MVP Dependencies

Install project dependencies:

```bash
npm install
```

The planned dependencies are:

- React
- React DOM
- Vite
- TailwindCSS
- PostCSS
- Autoprefixer
- Framer Motion
- Lucide React

## Optional Dev Dependencies

Testing can be added after the MVP flow works:

```bash
npm install -D vitest @testing-library/react @testing-library/jest-dom jsdom
```

## Do Not Add For MVP

Do not add these for Version 1:

- Express
- MongoDB
- authentication libraries
- backend routing
- admin tooling
- cloud deployment tooling

The MVP stores progress locally and uses static scenario data.
